# 暗黑2 iOS 移植 · 云端构建（你不需要 Mac）

一句话：**你不用买/借 Mac**。我把整套编译流水线写成了 GitHub Actions，
推到 GitHub 后，GitHub 自己的云端苹果电脑会替我们把 iPhone 安装包（.ipa）编出来。

---

## 你只需要做两件事

### ① 把文件夹推到 GitHub（双击一个脚本）
本文件夹里已有一个 **`一键推送到GitHub.bat`**：
- 双击它（Windows 上直接双击，不用开命令行）
- 它会问你 3 个问题，照着填：
  1. **GitHub 用户名** —— 你 github.com 的账号名
  2. **Token** —— 去 https://github.com/settings/tokens 点 "Generate new token"，
     **勾选 `repo`** 权限，生成后复制那一串字符粘进去（只显示一次，存好）
  3. **仓库名** —— 直接回车用默认的 `d2-ios-port` 就行
- 脚本会自动建仓库、上传代码。

> 更省事的办法：在 WorkBuddy 左侧「连接器」里把 **GitHub 连一下（点信任）**，
> 剩下的建仓库、推送、点构建我全帮你点完，你什么都不用填。

### ② 点一下"运行构建"，等包出来
1. 浏览器打开刚建的仓库 `https://github.com/你的名/d2-ios-port`
2. 点上方 **Actions** 标签
3. 左侧选 **Build iOS IPA (AbyssEngine + OpenDiablo2)**
4. 点 **Run workflow**
5. 等 **20~40 分钟**（第一次会现编一堆依赖，慢一点正常）
6. 完成后在页面里的 **Artifacts** 下载 `AbyssEngine-D2-iOS.ipa`

### ③ 装到 iPhone
- 电脑装个 **AltStore** 或 **Sideloadly**（免费），把 .ipa 拖进去装到手机
- 免费账号每 7 天要重签一次（重新点一下就行）

## 还需要你准备的（和 Mac 无关）
- **你自己的正版《暗黑破坏神2：毁灭之王》数据文件（MPQ）** —— 这是合法前提。
  云端编出来的是"空引擎"，第一次打开要把你正版游戏的数据放进去才能玩。
  具体放法见 `README-iOS.md` 的"数据放置"一节。
- 一个 **GitHub 账号**（免费）。

---

## 可能遇到的坑（提前说清楚）
- **ffmpeg 编译偶发失败**：游戏过场视频依赖它，iOS 上编起来偶尔抽风。
  若构建红掉，先看日志是不是 ffmpeg；是的话按 `README-iOS.md` 的"ffmpeg 兜底"处理，
  或把仓库地址发我，我远程修。
- **第一次构建慢**：要现编 sdl2/ffmpeg 等依赖，二三十分钟正常。
- **游戏本体可玩度**：云端只解决"能不能编出包"，但 OpenDiablo2 社区还没把
  玩法做完（现在仅主菜单+过场）。包能装、能进菜单，但完整通关还要等社区进度——
  这部分我按周报帮你盯着。
